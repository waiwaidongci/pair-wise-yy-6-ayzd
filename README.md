# 纸样水样准入与温湿度校正台（墨锭试磨）

运行：

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/ink-stick-testing.json`。

## 模块划分

- `server.js`：HTTP 入口、路由、页面（卡片/统计）
- `src/rules.js`：判定规则——准入、纸样去重、温湿度校正、复测与失效留档、状态与统计
- `src/store.js`：记录存储——JSON 文件读写，不含判定

## 业务规则

1. **每次试磨绑定同批宣纸和水样**：纸样批次、纸张克重、水样批次、水样硬度一起提交。
2. **准入（409 不落库）**：纸张克重或水样硬度缺失（含非数值、克重 ≤ 0）返回 `409 admission_incomplete`，不写任何记录；批次未填为 `400`。
3. **同一纸样只能有一条未封存试磨**：按纸样批次全局去重。重复提交沿用首次记录（返回 200 与 `reused: true`）；纸样已被其他墨锭占用返回 409。
4. **温湿度校正**：允许区间 18–25℃、40–60%RH。区间内按基准 20℃ / 50%RH 校正：
   `校正分 = round(原始分 + (20-温度)×1 + (50-湿度)×0.2)`，结果截断到 0–100；≥85 为合格。
5. **越界只转待复测**：温湿度越界（或缺失/非数值）不出校正分，记录状态为「待复测」，原始分留档。
6. **复测须换纸样**：对「待复测」件用新纸样复测，原卷自动封存；对着封存件再用同纸返回 409。
7. **调整水样或纸张使原结论失效**：原「已判定」且未封存的记录转为「失效留档」，记录留档但不计统计、不参与墨锭状态推导。封存件为永久档案，不失效。
8. **状态与统计单一来源**：墨锭状态（待试磨 / 待复测 / 已试磨 / 重点观察 / 已封存）由最近一条有效试磨在服务端推导，卡片、统计和刷新后完全一致。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/items` | 墨锭列表（含推导状态与全部试磨） |
| GET | `/api/stats` | 状态统计（失效留档单独计数） |
| POST | `/api/items` | 墨锭建档 |
| POST | `/api/items/:id/tests` | 提交试磨（准入/去重/校正/复测/失效判定） |
| POST | `/api/tests/:id/seal` | 封存试磨 |
