# 纸样水样准入与温湿度校正台

由「墨锭试磨室」扩展而来。每次试磨绑定同批宣纸（批号）与水样（编号），评分按
20℃、50% 湿度做线性校正。

## 运行

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/calibration-bench.json`
（旧文件 `data/ink-stick-testing.json` 为历史台账，不再使用）。

## 模块划分

- `store.js` — 记录存储：JSON 台账读写与种子数据，不含任何判定。
- `rules.js` — 判定规则：纸样/水样准入、试磨绑定、温湿度校正、复测、失效留档、统计。
- `server.js` — 入口：HTTP 路由与页面编排，卡片和统计共用 `/api/overview` 同一份快照，
  保证刷新后一致。

## 规则

1. **准入 409**：纸张克重或水样硬度缺失，纸样/水样登记以及试磨绑定均返回 `409`，
   错误发生在落库之前，台账不产生任何记录。
2. **同纸样幂等**：同一批纸样只能有一条未封存（未封存/待复测）试磨；重复提交
   返回首次试磨单（`reused: true`，HTTP 200），不新增记录。
3. **校正**：`校正分 = 原始分 − |温度−20|×0.8 − |湿度−50|×0.3`，校正分 ≥ 85 为合格。
4. **温湿度越界**：温度允许 18~22℃、湿度允许 45%~55%；越界只转「待复测」，
   校正分照算但不出结论、不计统计。
5. **复测**：复测必须更换纸样（同批拒绝，409）；原单与复测单互相留痕。
6. **调整失效**：封存/未封存单调整纸样或水样时，原结论转「失效留档」并另立新单；
   留档单永远不计统计，墨锭状态也由其余有效试磨推导。
7. **封存**：仅温湿度合格的未封存单可封存；封存合格是墨锭「已试磨」的唯一来源。

## API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/overview` | 卡片与统计共用的全量快照 |
| POST | `/api/sticks` `/api/papers` `/api/waters` | 墨锭建档 / 纸样准入 / 水样准入 |
| POST | `/api/tests` | 创建试磨（墨锭+纸样+水样+温湿度+原始分） |
| POST | `/api/tests/:id/seal` | 封存 |
| POST | `/api/tests/:id/retest` | 复测（体中须给不同 `paperBatch`） |
| POST | `/api/tests/:id/adjust` | 重录环境/评分，或调整纸样/水样 |
